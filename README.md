# 物理大富翁

這是一個可部署到 GitHub Pages 的靜態網頁遊戲。主頁是 `index.html`，遊戲初始資料放在 `assets/js/game-data.js`。

## 開啟方式

直接用瀏覽器開啟 `index.html`，或部署到 GitHub Pages 後開啟網站首頁。

## 基本測試

1. 進入首頁後點選「同一台螢幕玩 (單機模式)」。
2. 玩家 1 擲骰，確認棋子移動並出現購地、機會、命運、稅金或物理題目事件。
3. 若出現購地視窗，點「全額現購」，確認金額扣除、土地歸屬顯示，並切換到玩家 2。
4. 玩家 2 擲骰並完成事件，確認回合能回到玩家 1。
5. 點玩家頭像，修改名稱或圖示後儲存，確認玩家名稱與回合提示同步更新。

## 線上對戰

線上模式使用 PeerJS P2P：

- 房主點「建立對戰房間」產生 6 位房號。
- 對手輸入房號加入。
- 遊戲狀態會在兩端同步。

P2P 連線會受瀏覽器、校園/公司網路、防火牆與 NAT 影響；若連不上，先用單機模式確認玩法流程正常。

## 開發備註

瀏覽器 Console 可呼叫 `window.__getGameState()` 查看目前遊戲狀態，方便做冒煙測試與除錯。
